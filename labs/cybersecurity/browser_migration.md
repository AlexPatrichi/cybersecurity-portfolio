# 🧪 Browser Migration: Google Chrome to Mozilla Firefox

Platform: Windows 11  
Lab Type: Software Evaluation  
Difficulty: Beginner  

## 🎯 Objective
- Evluate the default web browser and migrate to a browser better suited for privacy, development, and cybersecurity learning while creating a consistent browsing experience across desktop and mobile devices.

## 🖥️ Environment
### Desktop
- Windows 11
- HP OMEN Laptop

### Mobile
- Android

## 🧰 Tools Used
- Google Chrome
- Mozilla Firefox
- DuckDuckGo Search

## 🔍 Initial Assessment
Google Chrome was the default browser on both desktop and mobile devices.  

While Chrome provides excellent compatibility and strong security, it was decided to migrate to Firefox to better align with privacy preferences and cybersecurity learning objectives.  

A privacy-focused search engine was also considered as part of the migration.

## 📋 Evaluation
### Google Chrome
Advantages:  
- Excellent website compatibility
- Frequent security updates
- Large extension ecosystem
- Strong synchronization across Google services  

Considerations:  
- Extensive integration with Google services
- Higher levels of telemetry compared with Firefox's default configuration
- Less flexibility for privacy-focused customization

### Mozilla Firefox
Advantages:  
- Open-source browser
- Enhanced Tracking Protection
- Strong privacy controls
- Highly customizable
- Excellent support for developer tools
- Well suited for security research and web testing

### DuckDuckGo
Reasons for Selection:  
- Privacy-focused search engine
- Does not build a personal search profile in the same way as traditional search engines
- Minimal tracking
- Consistent search experience across desktop and mobile devices

## 🛠️ Actions Taken
- Installed Mozilla Firefox on desktop and mobile
- Imported bookmarks
- Set Firefox as the default browser
- Enabled Enhanced Tracking Protection
- Configured DuckDuckGo as the default search engine

### Browser Add-ons
Installed the following Firefox extensions to improve privacy, security, and productivity:  
- **uBlock Origin** – Blocks advertisements and malicious or intrusive content.
- **Bitwarden** – Secure password manager for storing and generating strong passwords.

## ✅ Results
- Reduced dependence on Google services
- Improved privacy controls
- Consistent browser experience across desktop and mobile
- Privacy-focused search using DuckDuckGo
- Enhanced browser security and productivity using trusted extensions
- Better alignment with cybersecurity and development workflows

## 💡 Lessons Learned
- Selecting software should involve evaluating functionality, privacy, security, and usability rather than simply choosing the most popular option.

- Migrating from Google Chrome to Mozilla Firefox, together with adopting DuckDuckGo as the default search engine, created a browsing environment that better supports my privacy preferences while providing the tools and flexibility needed for software development and cybersecurity learning.

- This lab also reinforced the importance of maintaining a consistent configuration across multiple devices to improve both usability and security.
