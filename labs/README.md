# 🧪 Hands-On Labs

This directory contains practical, hands-on labs performed on real systems and virtual environments.

These labs complement the learning notes from **TryHackMe** and **Solent University coursework** by documenting real-world implementations, troubleshooting, hardware maintenance, system administration, and cybersecurity exercises.

## 🎯 Purpose

Each lab aims to:

- Apply concepts learned through study and training.
- Document a structured troubleshooting or implementation process.
- Record findings, actions taken, and results.
- Build a portfolio demonstrating practical IT and cybersecurity skills.
