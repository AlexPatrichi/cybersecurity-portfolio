## 🧠 Core Concepts Learned
## What is a GUI?
- A **Graphical User Interface (GUI)** allows users to interact with the operating system using windows, icons, menus, and a pointer instead of typing commands.
- Windows is primarily designed around its GUI, making it accessible to users of all experience levels.

### Desktop
The **Desktop** is the main workspace displayed after logging in to Windows.

It typically contains:
- Application shortcuts
- Files and folders
- The Recycle Bin
- The Taskbar

### Start Menu
The **Start Menu** is the central hub for accessing Windows.

From the Start Menu you can:
- Launch installed applications.
- Search for files, folders, and settings.
- Access power options such as **Shutdown**, **Restart**, and **Sleep**.
- Open Windows Settings.

### Taskbar
The **Taskbar** is located at the bottom of the screen by default.

It provides quick access to:
- Running applications.
- Pinned applications.
- The Start Menu.
- The Search feature.
- The Notification Area (System Tray).

### Notification Area (System Tray)
Located on the right side of the taskbar, the notification area displays:
- Date and time.
- Network status.
- Volume controls.
- Battery status (laptops).
- Background applications and system notifications.

### File Explorer
**File Explorer** is Windows' built-in file manager.

It allows users to:
- Browse files and folders.
- Copy, move, rename, and delete files.
- Access local drives, USB devices, and network locations.

### Settings
The **Settings** application is used to configure Windows.  

Common categories include:
- System
- Network & Internet
- Personalization
- Accounts
- Privacy & Security
- Windows Update

### Windows
Applications run inside **windows**, which can be:
- **Minimized** – Hidden from view but still running.
- **Maximized** – Expanded to fill the screen.
- **Restored** – Returned to their previous size.
- **Closed** – Exited completely.

### Keyboard Shortcuts
Some of the most useful Windows shortcuts include:  

| Shortcut | Action |
|----------|--------|
| **Win** | Open the Start Menu |
| **Win + E** | Open File Explorer |
| **Win + I** | Open Settings |
| **Win + L** | Lock the computer |
| **Alt + Tab** | Switch between open applications |
| **Win + D** | Show or hide the Desktop |
| **Ctrl + Shift + Esc** | Open Task Manager |

- Many security tools, logs, and administrative utilities are accessed through the graphical interface.
- Recognising standard Windows components makes it easier to identify unusual behaviour or suspicious applications.
