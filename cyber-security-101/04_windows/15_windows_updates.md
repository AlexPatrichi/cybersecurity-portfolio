## What is Windows Update?
**Windows Update** is a built-in Windows service that downloads and installs updates from Microsoft.

Updates can:
- Fix security vulnerabilities.
- Fix bugs and system problems.
- Improve stability and performance.
- Add or improve Windows features.
- Update security definitions and some drivers.

### Patch Tuesday
Microsoft typically releases Windows updates on the **second Tuesday of each month**, known as **Patch Tuesday**.

Critical or urgent security updates don't have to wait for Patch Tuesday and can be released earlier through Windows Update.

### Automatic Updates
In the past, Windows users could ignore updates for long periods.

Since Windows 10, updates can usually be postponed, but not ignored indefinitely. Eventually, Windows will install required updates and may restart the computer to complete them.

This helps keep Windows devices safe and secure.

## Checking for Updates
Windows updates can be managed through:
**Settings → Windows Update**

From here, you can:
- Check for updates.
- Download and install available updates.
- View update history.
- Restart the computer when required.

> Some updates require a system restart to complete the installation.

## Patching
**Patching** is the process of fixing vulnerabilities or problems in software by installing updates.

Vulnerability discovered → Microsoft releases a patch → Windows Update installs the patch → Vulnerability is fixed.
