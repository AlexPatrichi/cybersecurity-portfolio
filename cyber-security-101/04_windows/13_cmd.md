## What is Command Prompt?
**Command Prompt (CMD)** is Windows' built-in command-line interpreter that allows users to interact with the operating system by typing commands instead of using the graphical interface.

It is commonly used for:
- Navigating the file system
- Managing files and folders
- Viewing system information
- Running administrative and troubleshooting commands
- Executing scripts and batch files

### Command Syntax
Most commands follow this basic structure:

```text
command [options] [arguments]
```
- Command – The action to perform.
- Options (switches) – Modify how the command behaves (often begin with /).
- Arguments – The target the command acts on, such as a file or folder.

## 🔐 Security Relevance
Command Prompt is widely used by:

- System administrators for managing Windows systems.
- Security analysts during investigations.
- Penetration testers for enumeration and automation.
- Attackers to execute commands, gather system information, and move through a system.

Understanding CMD helps defenders recognize suspicious command activity and investigate incidents more effectively.
